# Setting up the server

## 1. Open Config

With no working configuration, Cronopus opens the [[Config]] page by itself.

## 2. Configure the database

Pick one mode:

- `PostgreSQL` — give the full connection string;
- `SQLite` — give a path to the database file.

A PostgreSQL example:

```text
Host=127.0.0.1;Port=5432;Database=postgres;Username=postgres;Password=secret;Search Path=Cronopus;Ssl Mode=Disable
```

`Search Path` selects the schema. Cronopus does not require the `public` schema.

## 3. Configure the HTTP server and logs

Set the dashboard port and the log and report folders if the defaults do not suit you.

## 4. Save

After saving, the configuration is re-read and the database connection is refreshed without editing individual PostgreSQL fields by hand.

## 5. Extra data

Config can import only:

- proxies;
- EVM addresses;
- SOL addresses.

Active modules prepare their own tables automatically.
