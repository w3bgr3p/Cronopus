# z3nDash

z3nDash — дашборд для расписаний, ZennoPoster-узлов, логов, HTTP-трафика и вспомогательных инструментов.

Сам дашборд работает на машине, где запущен: встроенный сервер слушает только `localhost`. Узлы, которыми он управляет, при этом могут быть где угодно в сети.

[[Remote Tasker]] подключает другие экземпляры z3nDash через отдельный, включаемый
по желанию HTTPS-сервер. Настройте его в [[Config]], затем выберите узел в [[Tasker]].

Оконная сборка — под Windows. Таргет `net10.0` собирается без WinForms: окна нет, адрес дашборда печатается в консоль и открывается в системном браузере. Вне Windows недоступна только [[System Snapshot]] — она читает счётчики и службы Windows.

## Запуск

1. Приложение загружает `appsettings.secrets.json`.
2. Если база настроена, z3nDash подключается к ней и открывает Tasker.
3. Если конфигурации нет, открывается Config.
4. Встроенный HTTP-сервер по умолчанию слушает порт `33333`.

## Хранилище

z3nDash поддерживает:

- PostgreSQL через единый connection string;
- SQLite через путь к файлу.

Для PostgreSQL схема берётся из `Search Path` connection string. Таблицы, которые нужны активным обработчикам, создаются автоматически.
