# Remote Tasker

Локальный z3nDash управляет Tasker другого экземпляра через HTTPS по IP.
Планировщик и скрипты выполняются на сервере независимо от подключения клиента.

## Первое подключение

1. Один раз откройте серверный z3nDash через RDP: **Config → Remote Tasker**.
2. Укажите **Public/server IP**, адрес прослушивания и порт (по умолчанию `38473`).
3. Включите HTTPS server и нажмите **Apply server settings**. Разрешите фактический
   порт в firewall сервера и, если требуется, в панели хостинга.
4. Создайте именованный ключ. Скопируйте ключ, Node ID и SHA-256 сертификата.
5. В локальном Tasker откройте список узлов → **+ New connection…**.
   В модалке укажите имя, `https://IP:port`, Node ID, fingerprint и ключ,
   затем **Add connection**. Сервер сохранится и будет выбран сразу.
   Добавление и проверка также доступны в Config → Remote Tasker → Connections.
6. На странице Tasker выберите сервер в верхнем списке узлов.

Если порт занят, сервер выбирает свободный. Фактический URL и причина видны
в Config; сохраните этот порт в настройках для следующего запуска.
Домен и внешний центр сертификатов не нужны: клиент проверяет IP, срок действия,
Node ID и закреплённый fingerprint. Старые токены Task API не дают доступ к мосту.

## Управление

Создание и клонирование задач, Settings, Payload, From Script, расписания,
пауза/возобновление, запуск, остановка и очередь относятся к выбранному серверу.
Пути скриптов и каталогов выбираются на сервере. Доступны его диски и каталоги
в пределах прав Windows-пользователя, под которым запущен z3nDash.
При конфликте версий сохранение отклоняется: перечитайте задачу и повторите правку.
Переключение узла предлагает сохранить или отбросить несохранённые изменения.
Оставшиеся шаги групповой команды прекращаются при переключении.

Время расписаний вычисляет сервер. API сообщает UTC; локальная машина не переносит
свою временную зону на сервер. Нативный терминал и редактор остаются локальными.

## Загрузка скриптов

**Upload file / Upload folder** открывает нативный выбор источника на локальной
машине, затем выбор назначения на сервере. Передача сохраняет дерево и пустые
каталоги; ссылки пропускаются. Используйте новый каталог при обновлении проекта,
который сейчас выполняется. Загрузка сама не меняет задачу и не перезапускает её.
После завершения **Choose uploaded script** позволяет выбрать новый script_path.

Передача идёт блоками 4 МиБ с SHA-256. При разрыве доступен Resume; после
перезапуска локального приложения незаконченная передача помечается interrupted.
Существующие файлы заменяются только после отдельного подтверждения каждого пути.
Commit атомарен для одного файла; всё дерево не является одной транзакцией.
Лимиты: 10 000 файлов, 20 ГиБ на файл, квота staging по умолчанию 40 ГиБ,
8 МиБ/с. Квота и скорость настраиваются в Config. Сессии истекают через 24 часа.
Публикация загруженных файлов поддержана сервером Windows.

## Логи и ошибки связи

Логи загружаются только по запросу: Load / Older / Observe. По умолчанию поток
отключён. Страница: 200 записей и 256 КиБ; один поток на ключ, до 64 КиБ/с.
В браузере хранится 2000 записей, общий буфер моста ограничен 64 МиБ и 15 минутами.
Пропуски при вытеснении отмечаются. Старый сохранённый вывод читается хвостом.

При неизвестном результате команды используйте **Check commands**. Не повторяйте
запуск автоматически: команда могла выполниться до потери ответа. Журнал хранит
результаты семь дней. Долгие build/install операции показывают ограниченный прогресс.

Отзыв ключа прерывает его наблюдение и передачи. Смена IP перевыпускает сертификат:
обновите fingerprint во всех клиентах. При истечении сертификата также смените
сертификат кнопкой **Renew certificate** и обновите fingerprint клиентов.
Ключи соединений и сертификат хранятся с защитой Windows DPAPI текущего пользователя;
не переносите state-файлы в другой Windows-профиль. API не принимает сертификат
с неправильным pin или IP и не следует HTTP-перенаправлениям.

Для запуска без окна панели: `z3nDash.exe --headless`. Сервер всё равно должен
работать; эта команда не устанавливает Windows-службу. При недоступности проверьте
фактический URL, firewall, IP, срок сертификата и актуальность ключа.
