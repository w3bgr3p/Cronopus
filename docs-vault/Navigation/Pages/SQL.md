# SQL

SQL — отдельная панель для SQLite-файлов и подключения к PostgreSQL.
Тип базы выбирается в заголовке. Страница открывается по прежнему адресу
`/?page=sqlite` и не меняет основную БД z3nDash.

## SQLite

- открыть файл базы;
- получить список таблиц;
- выполнить запрос;
- изменить значение;
- удалить строку.

SQLite работает с выбранным файлом, переданным в viewer API. Доступное
редактирование ячеек и удаление строк относятся только к SQLite.

## PostgreSQL

Выберите `PostgreSQL`, введите connection string и нажмите `Connect`.
Панель показывает доступные таблицы и представления вместе с именами схем.
Выбор таблицы формирует запрос на первые 1000 строк; свой запрос можно выполнить
из поля SQL. Поддерживаются `SELECT` и `WITH` с результатом для чтения.

Запросы выполняются в транзакции только для чтения. Результат ограничен
10 000 строками; при усечении появляется сообщение. Для больших таблиц
уточняйте запрос через `WHERE` или `LIMIT`. Подключение ограничено 10 секундами,
команда — 30 секундами, весь запрос — 40 секундами.

Изменение данных PostgreSQL и сохранённые профили подключения не поддерживаются.
Connection string хранится только на текущей странице и очищается при смене
источника или перезагрузке.

## API

- `POST /sqlite-viewer/tables`
- `POST /sqlite-viewer/query`
- `POST /sqlite-viewer/update`
- `POST /sqlite-viewer/delete`
- `POST /postgres-viewer/tables`
- `POST /postgres-viewer/query`
